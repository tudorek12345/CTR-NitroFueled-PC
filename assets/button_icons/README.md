# Xbox button icons

`xbox.png` contains controller prompts from **Xelu's Free Controller & Key Prompts**,
by Nicolae "Xelu" Berbece / [Those Awesome Guys](https://thoseawesomeguys.com/prompts/),
released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
The sheet contains no game pixels. CC0 applies to this sheet, separately from the GPL code.

The prearranged sheet is copied unchanged from
[martijnhe/OCTR-NitroFueled-PC-EU, commit bc034670949fe629685b36e2c50044ceee642ed7](https://github.com/martijnhe/OCTR-NitroFueled-PC-EU/blob/bc034670949fe629685b36e2c50044ceee642ed7/assets/button_icons/xbox.png).
Its Git blob SHA-1 is `97fc6c7ac83c84a37f844483963d62cd5fd589cf`.

`tools/xbox_button_icons.py` fits these icons into both base-game and update font layouts
in the player's own prepared CUSA13795 game folder. See
[the setup instructions](../../docs/sacredfire/18-pc-split-screen.md).
Xbox and PlayStation names identify button layouts; this project is not endorsed by their owners.
